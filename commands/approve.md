description: Approve the design preview (only you, the customer, can do this)
---

The customer just used the approve command. Their own message is what records
the approval. It was recorded automatically if the project was waiting for it,
and your session context says so.

- **If the approval was recorded:** run `piezas phase advance` with the Piezas
  command from your session context. Then tell them in one sentence what happens
  next.
- **If nothing was waiting for approval:** tell them where things stand in one
  sentence.

Never run the approve command yourself. It is blocked.
